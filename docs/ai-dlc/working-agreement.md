# AI Agent Working Agreement

## Ownership

- Humans own product outcomes, constraints, risk policy, exceptions, and final accountability.
- Agents may own implementation of eligible tickets from approved specification to initial pull request.
- Agent-first means the agent creates the initial implementation, tests, and PR; human implementation before the first PR disqualifies the example.

## Entry and exit

- No specification, no autonomous assignment.
- Every ticket has a task tier and required verification suites before Todo.
- Agents stop on missing decisions, scope expansion, protected paths, retry/runtime/cost limits, or unavailable verification.
- Configuration is not S2 evidence; observed executions and outcome metrics are required.

## Review tiers

- Low: eligible for policy-based auto-merge after all checks.
- Standard: one outcome reviewer.
- High: full and named specialist review.
- Prohibited: no autonomous execution.

## Cadence

- Review recurring failures monthly.
- Review this agreement quarterly and after any material agent incident.
- Owner: To be assigned.
